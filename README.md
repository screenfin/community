# Screenfin

Watch parties for Jellyfin on iPhone, iPad, Apple TV, Android TV, Android and the web. Everyone
plays straight from your own Jellyfin, and the Screenfin server you run beside it keeps the room in
sync. More at [screenfin.app](https://screenfin.app).

This is where Screenfin's bug reports, feature requests and release notes live.

| I want to…                        | Go to                                                              |
| --------------------------------- | ------------------------------------------------------------------ |
| Get the app                       | App Store · Google Play _(links land with the first release)_      |
| Use it in a browser               | Your own Screenfin server's address — the web client comes with it |
| Self-host the server              | [Self-hosting guide](https://screenfin.app/docs/)                  |
| Report a bug or request a feature | [New issue](../../issues/new/choose)                               |
| Ask how something works           | [Discussions](../../discussions)                                   |
| Billing or account questions      | support@screenfin.app — never in a public issue                    |
| Report a security problem         | [SECURITY.md](SECURITY.md)                                         |
