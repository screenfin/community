# Security

The Screenfin server is something people expose to the internet, so this matters more than usual.

**Report privately.** Use GitHub's private vulnerability reporting on this repository (Security →
Report a vulnerability) or email security@screenfin.app. Do not open a public issue.

**What to include:** which part (the server, the web client or an app), the version, and how to
reproduce it. You will hear back within a few days.

**What we most want to hear about.** The server never stores or logs anyone's Jellyfin token and
holds no credential of its own. A report that shows otherwise is exactly what this file is for.
